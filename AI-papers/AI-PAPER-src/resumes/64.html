Le problème

En 2023, les agents fondés sur des LLM se multiplient : ReAct (papier 56), Reflexion (papier 60), Voyager dans Minecraft, les « Generative Agents » qui simulent un village, AutoGPT… Chacun utilise un vocabulaire propre, et il est difficile de les comparer ou de voir ce qui manque. Theodore Sumers, Shunyu Yao, Karthik Narasimhan et Thomas Griffiths (Princeton) proposent un cadre conceptuel commun, CoALA (Cognitive Architectures for Language Agents), inspiré de cinquante ans de recherche sur les architectures cognitives comme Soar et ACT-R.

L'analogie

Les architectures cognitives classiques utilisaient des systèmes de production : des règles « si condition, alors action » qui réécrivent des chaînes de symboles. Un LLM fait quelque chose d'analogue de façon probabiliste : il réécrit un texte en un autre. Les architectures cognitives ajoutaient à ces règles une mémoire, des boucles de décision et de l'apprentissage. CoALA propose de faire de même autour des LLM.

Les trois dimensions

  • Mémoire :
    • mémoire de travail : l'état courant (observations, objectifs, résultats intermédiaires) ;
    • mémoire épisodique : les expériences passées (trajectoires, réflexions de Reflexion) ;
    • mémoire sémantique : les connaissances sur le monde (documents récupérés, faits) ;
    • mémoire procédurale : le savoir-faire, à la fois implicite (les poids du LLM) et explicite (le code de l'agent, les prompts, une bibliothèque de compétences).
  • Espace d'actions :
    • actions externes, ou d'ancrage : agir sur le monde physique, dialoguer avec des humains, utiliser des outils numériques ;
    • actions internes : raisonnement (lire et écrire la mémoire de travail), récupération (lire la mémoire à long terme), apprentissage (écrire dans la mémoire à long terme, y compris modifier son propre code ou ses poids).
  • Prise de décision : un cycle où l'agent planifie (propose, évalue, sélectionne des actions, éventuellement par recherche arborescente comme Tree of Thoughts, papier 59), puis exécute l'action choisie et observe le résultat.

Application aux agents existants

Le papier classe plusieurs agents dans ce cadre. Par exemple, ReAct n'a qu'une mémoire de travail et des actions de raisonnement et d'ancrage. Voyager ajoute une mémoire procédurale explicite (une bibliothèque de programmes) et apprend en y écrivant. Generative Agents combine mémoire épisodique, réflexion et planification. Cette grille fait apparaître les choix possibles et les manques.

Pistes proposées

  • Structurer les agents de façon modulaire plutôt qu'en prompts monolithiques.
  • Explorer davantage l'apprentissage, au-delà de l'ajout d'épisodes en mémoire : mise à jour des poids, écriture de code, réflexion.
  • Rendre les décisions plus délibérées, avec une planification explicite là où le coût d'une erreur est élevé.
  • Penser la sécurité : un agent capable de modifier son propre code ou ses poids est puissant mais risqué.

Héritage

CoALA a fourni le vocabulaire « mémoire épisodique, sémantique, procédurale » largement repris dans la conception des agents. Les mémoires persistantes des assistants actuels, les fichiers de compétences (« skills ») des agents de code et les bibliothèques d'outils réutilisables en sont des exemples concrets. La synthèse de 2026 sur le raisonnement agentique (papier 85) prolonge ce travail avec des agents qui s'améliorent eux-mêmes et collaborent.
