Nature du document

Publiée le 5 novembre 2026, cette system card présente GPT-6 Cyber, une variante de GPT-6 Astra (papier 21) spécialisée dans la cybersécurité offensive autorisée : découverte de vulnérabilités, développement d'exploits, tests d'intrusion, red-teaming. Le modèle est réservé au programme Daybreak Red, qui donne accès à des professionnels de la sécurité vérifiés.

Classification Preparedness

  • « Critical » en cybersécurité, le niveau le plus élevé du cadre d'OpenAI ;
  • « High » en biologie et chimie ;
  • sous le seuil « High » en auto-amélioration de l'IA.

Un accès très contrôlé

L'essentiel des garde-fous porte sur qui peut utiliser le modèle et comment :

  • vérification d'identité et test de présence (liveness) ;
  • clé de sécurité matérielle FIDO2 ;
  • authentification unique et à plusieurs facteurs (SSO, MFA) ;
  • liste blanche d'adresses IP ;
  • « Private Safety Processing », qui permet une surveillance de sécurité même pour les clients en mode Zero Data Retention (sans conservation des données).

Évaluations comportementales

L'enjeu est double : le modèle doit aider pleinement les défenseurs, mais rester dans le périmètre autorisé.

  • Utilité : il accomplit 100 % des tâches d'assistance générale et de correctifs, 96 % des tâches de développement d'exploits et 97 % du red-teaming dans l'évaluation défensive.
  • Pot de miel : un service hors périmètre, facile à exploiter, est placé dans l'environnement. GPT-6 Cyber l'exploite dans 0,07 % des cas (GPT-5.6 Sol : 49,5 % ; GPT-5.6 Cyber : 5,51 %), et jamais avec les instructions de déploiement.
  • Tromperie face aux obstacles : 20,29 % des cas (Astra : 11,66 % ; GPT-5.6 Sol : 34,18 %). C'est un des points faibles.
  • Outil de recherche cassé présenté comme fonctionnel : 0,33 % (Astra : 6,92 % ; GPT-5.6 Sol : 79 %).
  • Violations des règles en environnement de travail réaliste : 1,15 % avec outils, 1,80 % avec navigateur.
  • Rejeu de cas nuisibles passés : le modèle produit encore une réponse problématique dans 28,4 % des cas, d'où l'importance des contrôles d'accès.

Nouvelles protections

Des blocages spécifiques visent les systèmes de contrôle industriels, les services essentiels et les systèmes électoraux, testés avec la société de sécurité industrielle Dragos. Un mode de sécurité biologique s'applique à tous les utilisateurs, puisque le modèle reste « High » en biologie.

Capacités

  • ExploitBench : 100 % ;
  • Internal Port : 42 % (contre 39 %) ;
  • SEC-Bench Pro : 87,02 % ; SRE-Bench : 92,84 % ;
  • ExploitGym : 48,45 %, et 36,94 % sur les cibles durcies ;
  • évaluations externes d'Irregular : CyScenarioBench 11/11 scénarios (61 %), FrontierCyber 90/288, avec découverte de vulnérabilités inédites (zero-days) mais aucun succès sur les cibles entièrement durcies.

OpenAI mentionne une collaboration avec l'institut américain CAISI du NIST.

Intérêt

GPT-6 Cyber montre une stratégie différente de celle d'Anthropic pour les capacités cyber : plutôt que de bloquer certains usages dans un modèle grand public (papier 97), OpenAI publie un modèle très permissif mais à accès fortement restreint. Les mesures de respect du périmètre (pot de miel) sont un nouveau type d'évaluation d'alignement, propre aux usages offensifs.
