La question posée

Au début de 2024, un agent LLM agit le plus souvent en émettant un appel d'outil au format JSON, ou du texte selon un format fixe : une action par tour, avec des arguments typés. Xingyao Wang, Heng Ji et leurs coauteurs (Université de l'Illinois à Urbana-Champaign et Apple) proposent que l'action soit plutôt du code Python exécutable. Le code a des variables, des boucles et des conditions, il compose plusieurs outils en un seul tour et réutilise toutes les bibliothèques existantes. Les messages d'erreur de l'interpréteur servent aussi de retour pour se corriger.

Le dispositif

  • CodeAct : à chaque tour, le modèle écrit un bloc de code. Un interpréteur Python l'exécute et renvoie la sortie ou l'erreur comme observation, dans le schéma pensée–action–observation de ReAct (fiche 56).
  • M3ToolEval : un banc d'essai de tâches qui exigent de combiner plusieurs outils sur plusieurs tours, pour comparer CodeAct au JSON et au texte à action égale.
  • CodeActInstruct : 7 000 interactions multi-tours collectées avec CodeAct, qui servent à affiner Llama 2 et Mistral pour obtenir CodeActAgent.

Résultats

  • Sur 17 LLM, CodeAct égale ou dépasse le JSON et le texte, avec jusqu'à 20 points de taux de succès en plus et jusqu'à 30 % d'actions en moins.
  • L'écart est le plus grand pour les modèles les plus capables : ils savent tirer parti du contrôle de flux et des bibliothèques.
  • CodeActAgent sait entraîner un modèle avec scikit-learn ou tracer des courbes, et se corrige à partir des traces d'erreur. Ses capacités générales ne baissent pas après l'affinage.

Héritage

CodeAct est devenu l'agent par défaut d'OpenHands (fiche 112), du même premier auteur. L'idée a gagné tout l'écosystème. Les harnais de code donnent au modèle un shell et le laissent écrire ses propres scripts plutôt que de multiplier les outils spécialisés : Pi (dossier « Harnais », § 4) n'a que quatre outils, dont bash. Le « code mode » des clients MCP fait de même : il fait écrire au modèle du code qui appelle les outils, au lieu d'un appel JSON par outil.
