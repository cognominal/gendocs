La question posée

En mars 2024, Cognition présente Devin, un « ingénieur logiciel IA » fermé. En réaction, une communauté lance en quelques semaines OpenDevin, rebaptisé ensuite OpenHands : une plateforme ouverte pour construire, exécuter et évaluer des agents qui codent, naviguent sur le web et interagissent avec un ordinateur comme un développeur. Ce papier de Xingyao Wang, Graham Neubig et de nombreux contributeurs (UIUC, CMU, Yale, All Hands AI, etc.) en décrit l'architecture.

L'architecture

  • Flux d'événements : chaque action de l'agent (commande, code, navigation, message) et chaque observation qui en résulte est un événement enregistré dans un journal. C'est l'historique de l'agent, et il se rejoue.
  • Runtime isolé : chaque session a un conteneur Docker qui offre un shell bash, un noyau IPython et un navigateur Chromium piloté par Playwright. L'agent peut tout faire dans ce bac à sable sans toucher la machine hôte.
  • Agenthub : plusieurs agents interchangeables. Le principal, CodeActAgent, agit par code (fiche 108). Un agent de navigation et des micro-agents spécialisés complètent l'ensemble, et un agent peut déléguer une sous-tâche à un autre.
  • Des compétences (skills) sous forme de fonctions Python : ouvrir un fichier, éditer, chercher, lire un PDF.
  • Une suite d'évaluation intégrée de 15 bancs d'essai : SWE-bench, HumanEvalFix, WebArena, MiniWoB++, GAIA, GPQA, etc.

Résultats

  • CodeActAgent v1.8 avec Claude 3.5 Sonnet résout 26 % de SWE-bench Lite, au niveau des meilleurs systèmes spécialisés de l'époque. Sur WebArena et GAIA, les résultats restent corrects sans réglage spécifique à ces tâches.
  • Le projet compte alors plus de 32 000 étoiles GitHub et plus de 2 100 contributions de plus de 188 contributeurs, sous licence MIT.

Héritage

OpenHands (ICLR 2025) est devenu l'un des harnais de référence des bancs d'essai : Terminal-Bench (fiche 115) le compte parmi ses agents évalués. L'architecture en flux d'événements, avec un runtime en conteneur, se retrouve dans les agents de code « cloud » (Codex dans le cloud, Claude Code sur le web, Devin). Les entraînements par RL d'agents de code, qui exécutent des millions d'épisodes dans des bacs à sable, la reprennent aussi (voir DSec, fiche 44). Voir le dossier « Harnais », § 4.
