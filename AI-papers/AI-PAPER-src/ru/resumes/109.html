Поставленный вопрос

Человек программирует с редактором, терминалом и инструментами поиска, созданными для него. Языковой модели эти инструменты подходят плохо: cat большого файла переполняет её контекст, а интерактивный редактор вроде vim для неё бесполезен. Джон Ян, Карлос Хименес, Офир Пресс, Картик Нарасимхан и соавторы (Принстон) отстаивают идею, что нужно проектировать интерфейс агент—компьютер (ACI) для моделей, как проектируют интерфейс человек—машина для людей.

Устройство

SWE-agent даёт GPT-4 Turbo или Claude 3 Opus небольшой набор команд, рассчитанных на языковую модель:

  • просмотрщик файла, показывающий по 100 строк с номерами и перемещающийся командами scroll и goto;
  • команды поиска (find_file, search_dir, search_file), возвращающие краткую сводку вместо всего текста;
  • команду edit, которая заменяет блок строк и запускает линтер: правка, ломающая синтаксис, отклоняется, и ошибка показывается;
  • краткие ответы, включая явное сообщение, когда команда успешно выполнилась без вывода.

Авторы выводят четыре принципа: простые действия, компактные действия, краткая и информативная обратная связь и ограждения, не дающие ошибкам распространяться.

Результаты

  • На 2 294 задачах SWE-bench (реальные тикеты GitHub из проектов на Python) SWE-agent с GPT-4 Turbo решает 12,47 % (286). Лучший опубликованный до того результат, на основе генерации с поиском (RAG), составлял 3,8 %.
  • На SWE-bench Lite (300 задач) агент достигает 18,0 % против 11,0 % у той же модели с простым shell Linux: один интерфейс даёт 64 % относительного прироста.
  • Абляции показывают, что важен каждый принцип. Без линтера агент вязнет в сломанных правках; при слишком большом окне файла или полном выводе результатов поиска он теряется.
  • На HumanEvalFix SWE-agent достигает 87,7 % на Python.

Наследие

SWE-agent (NeurIPS 2024) — статья, показавшая, что обвязка значит не меньше модели. Инструменты чтения и правки Claude Code, Codex и Aider следуют её принципам: окна файлов, компактный поиск, проверенная правка. Затем команда выпустила mini-SWE-agent, агент из 100 строк, использующий только bash, ставший эталонной обвязкой для сравнения моделей.
