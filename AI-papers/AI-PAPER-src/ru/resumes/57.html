Парадокс

Большие языковые модели умеют решать новые задачи по нескольким примерам, но проваливаются на вещах, простых для программы: точная арифметика, свежие факты, сегодняшняя дата, малоресурсные языки. Внешние инструменты легко решают эти проблемы. Прежние подходы к соединению LLM и инструментов требовали либо обширной человеческой разметки, либо отдельного промпта для каждой задачи. Тимо Шик и его коллеги из Meta хотят, чтобы модель сама, в режиме самообучения, выучила, какие инструменты вызывать, когда, с какими аргументами и как использовать результат.

Метод

Вызовы API представлены как текст, вставленный в предложение, например: «Из 1400 участников 400 (то есть [Calculator(400/1400) → 0.29] 29%) справились». Конвейер состоит из трёх этапов:

  1. Выборка: имея несколько демонстраций для каждого инструмента в промпте, GPT-J предлагает в большом текстовом корпусе (подмножестве CCNet) позиции, где вызов мог бы быть полезен, и вызовы-кандидаты.
  2. Исполнение: каждый вызов выполняется, и его результат извлекается.
  3. Фильтрация: вызов сохраняется, только если он снижает потерю модели на следующих токенах по сравнению с отсутствием вызова или вызовом без результата. Иначе говоря, инструмент сохраняется, если он действительно помогает предсказать продолжение текста.

Затем модель дообучают на корпусе, обогащённом отобранными вызовами. Поскольку корпус остаётся тем же текстом, модель не теряет общих способностей к моделированию языка.

Инструменты

  • вопросно-ответная система (Atlas);
  • поиск по Википедии (BM25);
  • калькулятор;
  • календарь, возвращающий сегодняшнюю дату;
  • переводчик (NLLB) на английский.

Результаты

  • Toolformer (GPT-J, 6,7 миллиарда параметров) заметно превосходит GPT-J без инструментов и часто GPT-3 175B в режиме zero-shot на задачах знаний (LAMA), математики (ASDiv, SVAMP, MAWPS), вопросов-ответов и временного рассуждения.
  • Модель сама выбирает инструмент: калькулятор для математики, поиск для фактов.
  • Перплексия на обычном тексте не ухудшается.
  • Способность хорошо использовать инструменты появляется лишь начиная примерно с 775 миллионов параметров.

Ограничения

Инструменты нельзя выстраивать в цепочку (результат одного не служит входом другому), поскольку каждый вызов генерируется независимо. Модель не взаимодействует с инструментом: она не может переформулировать неудачный поиск. Для некоторых инструментов метод дорог в выборке, и модель остаётся чувствительной к точной формулировке входа при решении вызвать инструмент.

Наследие

Toolformer показал, что модель может научиться пользоваться инструментами по простому самообучающемуся сигналу. Несколько месяцев спустя OpenAI запустила вызов функций («function calling») в своём API, а затем плагины ChatGPT. Сегодня модели обучают непосредственно вызывать инструменты, часто в агентных циклах в духе ReAct (статья 56) и через протоколы вроде MCP, безопасности которых посвящена APPA (статья 95).
