Проблема

Качество LLM сильно зависит от данных предобучения. Однако крупные лаборатории публикуют мало подробностей о своих наборах данных и решениях о фильтрации. Открытые наборы (C4, The Pile, RefinedWeb, Dolma) были меньше или хуже. Гильерме Пенедо и команда Hugging Face (2024) публикуют FineWeb — набор данных из 15 триллионов токенов — и, главное, экспериментально обосновывают каждое решение при его построении.

Метод абляций

Для каждого решения авторы обучают модели на 1,8 миллиарда параметров на 28 или 350 миллиардах токенов, затем сравнивают результаты на наборе бенчмарков, выбранных так, чтобы давать надёжный сигнал уже на малых масштабах (CommonsenseQA, HellaSwag, OpenBookQA, PIQA, SIQA, WinoGrande, ARC, MMLU). Обучено более 70 моделей для абляций.

Конвейер

  1. Извлечение: 96 снимков Common Crawl (2013–2024). Извлечение текста из сырых файлов WARC с помощью trafilatura даёт лучшие результаты, чем готовые текстовые файлы WET.
  2. Базовая фильтрация: чёрный список URL, определение языка (английский), фильтры качества MassiveText.
  3. Дедупликация: MinHash на уровне документа. Контринтуитивный результат: дедупликация каждого снимка отдельно даёт лучшие результаты, чем глобальная дедупликация по всем снимкам. Глобальная дедупликация удаляет в основном качественные документы из старых снимков и оставляет большую долю низкокачественного содержания.
  4. Дополнительные фильтры: фильтры C4 (кроме слишком агрессивного фильтра строк без пунктуации) и новые эвристические фильтры, разработанные путём сравнения статистик хороших и плохих наборов данных.
  5. Анонимизация адресов электронной почты и IP.

FineWeb-Edu

Авторы также строят FineWeb-Edu: Llama-3-70B-Instruct оценивает 450 000 образцов по шкале от 0 до 5 по образовательной ценности, затем на этих оценках обучают небольшой классификатор и применяют его ко всему FineWeb. Сохраняя документы с оценкой 3 и выше, получают 1,3 триллиона токенов. Модели, обученные на FineWeb-Edu, сильно прибавляют на бенчмарках знаний и рассуждения: MMLU растёт с 33% до 37%, ARC — с 46% до 57% при равном бюджете. Чтобы достичь уровня моделей, обученных на других наборах, нужно примерно в 10 раз меньше токенов.

Результаты

Модели, обученные на FineWeb, превосходят модели, обученные на любых других открытых наборах данных того времени. Опубликованы набор данных, код (библиотека datatrove) и модели абляций.

Наследие

FineWeb и FineWeb-Edu стали стандартами для предобучения открытых моделей. FineWeb2 распространил подход на более чем тысячу языков. Идея использовать LLM для оценки образовательного качества данных получила широкое распространение. Работа делает публичным этап, долго остававшийся секретом, наряду с техническими отчётами открытых моделей, например DeepSeek (статья 32).
