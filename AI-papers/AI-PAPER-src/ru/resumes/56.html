Проблема

В 2022 году две линии исследований развиваются раздельно. С одной стороны, цепочка мыслей (статья 53) заставляет модели рассуждать, но только на основе внутренних знаний: они галлюцинируют факты и распространяют ошибки. С другой стороны, работы заставляют модели действовать в средах (веб-навигация, текстовые игры), но без явного рассуждения: они реагируют, не планируя. Шуньюй Яо и его коллеги (Принстон и Google) предлагают объединить обе: ReAct (Reasoning + Acting).

Метод

Модель порождает траекторию, чередующую три типа элементов:

  • Мысль: свободное рассуждение на естественном языке, ничего не меняющее в среде. Оно служит для разложения цели, отслеживания прогресса, обработки исключений, извлечения полезной информации из наблюдения или решения, что искать дальше.
  • Действие: команда, посылаемая в среду, например Search[Apple Remote], Lookup[keyboard] или Finish[ответ] для простого API Википедии.
  • Наблюдение: ответ среды, добавляемый в контекст.

Формат выучивается по нескольким примерам в промпте (PaLM 540B), затем дообучением для меньших моделей. Мысли могут быть частыми (перед каждым действием, в задачах рассуждения) или редкими (в длинных задачах принятия решений).

Результаты

  • HotpotQA (многошаговые вопросы) и FEVER (проверка фактов): ReAct сильно сокращает галлюцинации по сравнению с одной лишь цепочкой мыслей, поскольку ищет факты. Лучшая конфигурация сочетает ReAct и цепочку мыслей с самосогласованностью: переходят от одного к другому, когда первое не срабатывает.
  • ALFWorld (текстовая игра с бытовыми задачами): 71% успеха против 37% у имитации демонстраций, то есть +34 пункта.
  • WebShop (имитация онлайн-покупок): +10 пунктов успеха по сравнению с лучшими методами обучения.
  • После дообучения всего на 3000 траекторий малые модели ReAct превосходят большие модели с промптингом.

Анализ ошибок

На HotpotQA одна цепочка мыслей ошибается в основном из-за галлюцинаций (56% её ошибок). ReAct ошибается скорее из-за повторяющихся циклов рассуждения или поисков, не дающих ничего полезного. Рассуждение ReAct более фактично, но менее гибко. Другое преимущество: траектория читаема, и человек может исправить мысль по ходу, чтобы перенаправить агента.

Наследие

Цикл «мысль → действие → наблюдение» стал базовой схемой почти всех агентов на основе LLM: LangChain, AutoGPT, затем агентов программирования вроде Claude Code или Codex, с моделями, теперь обученными вызову инструментов. Reflexion (статья 60) добавляет к нему память о неудачах; CoALA (статья 64) превращает его в общую архитектуру; обзор агентного рассуждения (статья 85) прослеживает его потомство. Toolformer (статья 57), опубликованный вскоре после, показывает, как научиться пользоваться инструментами без промпта.
